Stop runaway AI agents before they burn your API key overnight

burnstop is a local circuit-breaker proxy for the Anthropic and OpenAI APIs. It meters every request, detects loops, and cuts the agent off with an instant 402 when a rule trips.

# terminal 1 $ pip install git+https://github.com/kelbic/burnstop && burnstop init && burnstop start # terminal 2: your agent, unchanged $ export ANTHROPIC_BASE_URL=http://127.0.0.1:8787

How it works

One local process between your agent and the provider. Streams pass through in real time; usage and tool calls are parsed on the fly.

max_usd_per_10m: 2.00

Real-time spend caps

Sliding 10-minute, hourly and daily budgets computed from each response's usage, including prompt-cache reads and writes. No waiting for a billing dashboard.

max_identical_tool_calls: 4

Infinite-loop detection

Trips when the agent requests the same tool with the same arguments again and again, hits a wall of upstream errors, or fires requests in a tight loop.

HTTP 402 + webhook

Instant kill switch

The next request gets a provider-shaped 402 that SDKs do not retry. One alert to Telegram, Slack or Discord, an optional SIGTERM, and a lockout that survives restarts.
